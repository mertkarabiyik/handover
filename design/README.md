# Ekran tasarımları

Canlı tuval: [Handover Ekran Tasarımı](https://claude.ai/artifact/22WStrMyChH5rzFhpv5NFm). Bu klasördeki dosyalar 17 Kasım 2026 kopyası; tuvalin çalışma ortamı olmadan açılmaz, referans içindir. Tuvalde değişiklik yapılınca buraya yeniden kopyalanır.

| Dosya | Ekran |
|---|---|
| `Main.dc.html` | Ana sayfa: bugünkü ders, partner notu, seviye yol haritası |
| `Ders.dc.html` | Ders: bass swap, 32 vuruşluk zaman çizelgesi, adımlar |
| `Drill.dc.html` | Drill: canlı vuruş sayacı, iki deck, deneme puanı |
| `B2B.dc.html` | AI partnerle B2B: oturum akışı, partnerin şarkısı, cevap seçenekleri |
| `Kesif.dc.html` | Keşif: türler, hot list, sete uyum, aktif setler, oynatıcı, mağaza linkleri |

Görsel dil: koyu kabin teması (#15121c), cue turuncusu (#ff7a2f), Unbounded başlık, Instrument Sans gövde, DM Mono sayılar. Şarkı ve DJ adları köşeli parantezli yer tutucu, sayılar örnek.
